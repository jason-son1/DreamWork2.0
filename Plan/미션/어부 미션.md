어부(Fisher) 직업 역시 **'단순 대기(AFK) 낚시'를 방지**하고, **[미끼-대어-납품]**으로 이어지는 전략적이고 경제적인 플레이를 유도하기 위해 미션 시스템을 개편합니다.

특히 어부는 **'살아있는 물고기(Live)'** 납품과 **'회(Sashimi)'** 가공이라는 두 가지 경제 루트를 미션에 적극 반영하여 설계했습니다.

# 🎣 어부(Fisher) 미션 마스터 플랜: "심해의 지배자"

## 1. 미션 진행 메커니즘: [진화형 미션]

낚싯대 하나만 던져놓고 잠수타는 것을 막기 위해, 미션은 **특정 어종**, **크기(Size)**, **신선도(Live)**, **도구 활용(미끼)**을 복합적으로 요구하는 형태로 진화합니다.

- **구조:** `Novice` (강가) → `Angler` (바다) → `Pro` (심해) → `Master` (대양) → `Legend` (신화)
    
- **특이점:** 어부는 **'시간대(새벽/밤)'**와 **'바이옴(정글/얼음)'**의 영향을 받는 미션이 포함됩니다.

## 2. 미션 상세 분류 및 콘텐츠

사용자님의 요청에 따라 **어부(Fisher) 미션 마스터 플랜**의 **[카테고리 A. 기초/수집]**을 구체화하여 상세 기획서를 작성해 드립니다.

기존 광부/농부 미션서와 동일한 톤앤매너를 유지하며, 마인크래프트 바닐라 시스템을 기반으로 **'바이옴 탐험'**과 **'부산물 재활용'**이라는 알짜배기 기능을 학습시키는 데 초점을 맞췄습니다.

```
// 미션 진행 중인 플레이어의 잡은 물고기 기록
public void onFish(PlayerFishEvent event) {
    if (event.getState() != State.CAUGHT_FISH) return;
    
    Item item = (Item) event.getCaught();
    Material fishType = item.getItemStack().getType();
    
    // 미션 체크 로직
    if (user.hasMission("tier_2")) {
        Set<Material> caughtList = user.getMissionData("tier_2_list");
        caughtList.add(fishType);
        
        if (caughtList.size() >= 4) {
            missionManager.completeMission(player, "tier_2");
        }
    }
}
```

## 2. 📏 미션 체인: [기록 경신] (Record Breaker)

**컨셉:** 물고기의 종류보다 **'크기(Size)'**에 집착하는 진짜 낚시꾼들을 위한 미션입니다. 바닐라 마인크래프트에는 없는 '크기 데이터'를 부여하여 경쟁심을 자극합니다.

### 💡 구현 로직 (Implementation Note)

1. **크기 생성 알고리즘 (Gaussian Distribution):**
    
    - 물고기를 잡는 순간(Item 생성 시), `PDC`에 `fish_size` 값을 저장합니다.
        
    - 기본 공식: `Base Size + (Random * Variance) + (Rod Tier Bonus)`

2. **연속 성공 판정:**

```
// PlayerFishEvent - CAUGHT_FISH 상태
public void applyFishStats(Item fishItem, Player player) {
    ItemStack stack = fishItem.getItemStack();
    ItemMeta meta = stack.getItemMeta();
    PersistentDataContainer pdc = meta.getPersistentDataContainer();
    
    // 1. 크기 결정 알고리즘
    double baseSize = 30.0; // Config에서 로드
    double randomSize = Math.random() * 40.0;
    double rodBonus = getRodTier(player.getInventory().getItemInMainHand()) * 5.0;
    
    double finalSize = baseSize + randomSize + rodBonus;
    // 소수점 1자리까지 반올림
    finalSize = Math.round(finalSize * 10.0) / 10.0;

    // 2. PDC에 저장 (NamespacedKey: "fish_size")
    pdc.set(new NamespacedKey(plugin, "fish_size"), PersistentDataType.DOUBLE, finalSize);
    
    // 3. Lore(설명) 업데이트
    List<String> lore = meta.getLore();
    if (lore == null) lore = new ArrayList<>();

        lore.add("§b[월척!]");
        player.playSound(player.getLocation(), Sound.ENTITY_PLAYER_LEVELUP, 1f, 1.5f);
    }
    
    meta.setLore(lore);
    stack.setItemMeta(meta);
    fishItem.setItemStack(stack);
}
```

## 3. ⌨️ 핵심 로직 구현 (Core Implementation)

### A. 물고기 생성 공장 (`FishFactory.java`)

마인크래프트의 일반 물고기를 **데이터가 담긴 DreamWork 물고기**로 변환하는 핵심 클래스입니다.

Java

```
public ItemStack createFish(Player player, Material originalType) {
    ItemStack fish = new ItemStack(originalType);
    ItemMeta meta = fish.getItemMeta();
    PersistentDataContainer pdc = meta.getPersistentDataContainer();

    // 1. 크기(Size) 계산 (가우시안 분포 활용)
    // 낚싯대 등급에 따라 평균 크기 보정 가능
    double baseSize = 30.0; 
    double variance = (new Random().nextGaussian() * 10) + (getRodLevel(player) * 2);
    double size = Math.max(10.0, baseSize + variance); // 최소 10cm
    size = Math.round(size * 10.0) / 10.0; // 소수점 첫째 자리

    // 2. PDC 데이터 주입 (플러그인이 식별할 태그)
    pdc.set(new NamespacedKey(plugin, "fish_size"), PersistentDataType.DOUBLE, size);
    pdc.set(new NamespacedKey(plugin, "fish_owner"), PersistentDataType.STRING, player.getUniqueId().toString());
    pdc.set(new NamespacedKey(plugin, "catch_time"), PersistentDataType.LONG, System.currentTimeMillis());
    
    // 3. 생사 여부 (기본적으로 낚시로 잡으면 죽음=false, 살림망 있으면 true)
    boolean isLive = hasFishKeep(player);
    pdc.set(new NamespacedKey(plugin, "live"), PersistentDataType.BYTE, (byte) (isLive ? 1 : 0));

    // 4. 로어(Lore) 업데이트
    List<String> lore = new ArrayList<>();
    lore.add("§7📏 크기: §f" + size + "cm");
    if (isLive) lore.add("§a[LIVE] §f살아있음");
    else lore.add("§7[DEAD] §f신선함");
    
    meta.setLore(lore);
    fish.setItemMeta(meta);
    return fish;
}
```

### B. 미션 체크 리스너 (`FisherMissionListener.java`)

낚시 성공 이벤트를 감지하여 미션 진행도를 업데이트합니다.

Java

```
@EventHandler
public void onFishCatch(PlayerFishEvent event) {
    if (event.getState() != PlayerFishEvent.State.CAUGHT_FISH) return;
    if (!(event.getCaught() instanceof Item)) return;

    Player player = event.getPlayer();
    Item caughtEntity = (Item) event.getCaught();
    ItemStack fishItem = caughtEntity.getItemStack();

    // 1. 물고기 데이터 변환 (위의 Factory 사용)
    fishItem = FishFactory.createFish(player, fishItem.getType());
    caughtEntity.setItemStack(fishItem); // 월드에 떨어진 아이템 교체

    // 2. 미션 매니저 호출
    MissionManager mm = DreamWork.getMissionManager();
    User user = mm.getUser(player);

    // [예시] 크기 미션 체크
    if (user.hasMission("big_catch")) {
        double size = fishItem.getItemMeta().getPersistentDataContainer()
            .get(new NamespacedKey(plugin, "fish_size"), PersistentDataType.DOUBLE);
        
        if (size >= 80.0) {
            mm.addProgress(player, "big_catch", 1);
            player.sendMessage("§b[어부] §f월척입니다! (" + size + "cm)");
        } else {
            // 연속 미션인 경우 실패 시 초기화 로직
            mm.resetProgress(player, "big_catch"); 
        }
    }
    
    // [예시] 미끼 소모 로직
    BaitManager.consumeBait(player);
}
```

```
}

@EventHandler
public void onCraft(CraftItemEvent event) {
    if (isFilletRecipe(event.getRecipe())) {
        // 칼은 소모되지 않고 내구도만 깎여서 돌려받아야 함 (바닐라 동작 방지)
        // 복잡하므로 보통은 커스텀 GUI나 우클릭 트리거를 권장하지만, 
        // 제작대 사용 시엔 Matrix를 조작해야 함.
        
        Player player = (Player) event.getWhoClicked();
        
        // 부산물(뼈) 추가 지급
        if (Math.random() < 0.5) { // 50% 확률
            player.getInventory().addItem(new ItemStack(Material.BONE));
            player.sendMessage("§7생선 뼈를 깨끗하게 발라냈습니다.");
        }
    }
}
```

_(Tip: 제작대 이벤트 제어는 복잡하므로, **칼을 든 채로 생선이 든 상자나 도마(특정 블록)를 우클릭**하여 즉시 변환하는 방식이 개발 공수가 적고 유저 경험(UX)도 좋습니다.)_
